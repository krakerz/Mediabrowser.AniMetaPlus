Recent requests

Untick TheTVDB and TheMovieDb in the anime library's settings and tick only AniMeta+. They stay installed, and AniMeta+ asks them itself where they are listed below. A provider ticked below AniMeta+ in the library fills fields AniMeta+ left empty, with its own data.

Pause: the item keeps what it has and waits. Switch: the next source fills in, and is replaced once this one answers again. Switch + review: the next source fills in, and the replacement waits for your review. Bans are per IP address. The gap between requests never goes below each source's default.

Source order

First listed is asked first. Genres, rating and cast combine every source listed. Ids: AniDB, AniList, MyAnimeList, TheTVDB, TheMovieDb.

AniDB

Every program must register its own client on AniDB (anidb.net, your profile, "Client registration"). AniDB is not asked anything while this is empty. A ban is per IP address: a different client name does not lift it.

MyAnimeList

Create a client id at myanimelist.net/apiconfig. Without one, MyAnimeList can still be read through Jikan, which MyAnimeList does not run.

AniList

Needs no key.

The AniDB titles dump is what anime are identified from. It is downloaded by the scheduled task or "Download now", and never more than once every 3 days, counted from the last attempt: AniDB bans a client that downloads it more than once a day.

Items nothing could identify. Pick a guess, search the titles dump, or paste an AniDB id or link. "Map" applies on the next queue run; "Map now" refreshes the item at once.

Mapped by hand

Accept takes the preferred source's value. Keep keeps the current one until the preferred source changes it. Lock keeps it for good.

Requests that failed, remembered so they are not sent again until they can succeed. Lift clears one and refreshes the item; Pin keeps it for good.
