AniMeta+ for Jellyfin (12.x)
============================

Easier: add the plugin repository in Dashboard > Plugins > Manage Repositories,
  https://raw.githubusercontent.com/krakerz/Mediabrowser.AniMetaPlus/manifest/manifest.json
and install AniMeta+ from the catalog; Jellyfin then offers updates itself.

By hand:
1. Create the folder <jellyfin config>/plugins/AniMetaPlus_1.2.0.0/ and copy
   AniMetaPlus.dll into it. When updating, replace the DLL in the AniMetaPlus_*
   folder you already have instead of adding a second folder.
     Linux package:  /var/lib/jellyfin/plugins
     Docker:         /config/plugins
     Windows:        %ProgramData%\Jellyfin\Server\plugins
2. Restart Jellyfin.
3. Open Dashboard > Plugins > AniMeta+:
   - Clients & keys: enter your own AniDB client name (register one on anidb.net,
     your profile, "Client registration") and press Test. AniDB is not asked
     anything until a client name is set.
   - Optional: a MyAnimeList client id, or turn on Jikan.
4. In your anime library's settings: tick AniMeta+ as metadata and image
   fetcher for Series, Season and Episode, and untick TheTVDB and TheMovieDb.
   AniMeta+ still uses them itself where its source order lists them (the
   TheTVDB plugin must be installed for TVDB data).
5. Optional: put AniDB's anime-titles.dat.gz in
   <plugins>/configurations/AniMetaPlus/ so anime can be identified at once;
   otherwise the "Refresh AniDB titles dump" task downloads it (at most once every 3 days).

Settings, blocks and mappings live in <plugins>/configurations/AniMetaPlus/.
